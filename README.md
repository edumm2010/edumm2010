## 🚀 Projeto em destaque

### 🌱 EcoMove — Projeto finalizado ✅

O **EcoMove** é um site desenvolvido para o projeto escolar **Ciclo Global — Carro Elétrico**, reunindo tecnologia, mobilidade elétrica e sustentabilidade.

O projeto apresenta conteúdos sobre a **história dos carros elétricos, globalização, cadeia produtiva, impactos socioambientais, tecnologia, logística, ciclo de vida e soluções sustentáveis**, além de páginas e recursos próprios do sistema.

**Tecnologias utilizadas:** HTML5 • CSS3 • Python
